# Career Compass AI

Build a production-quality AI-Powered Job Portal & Resume Analyzer as a portfolio project for a Python Full-Stack Developer fresher.

Use Python, Django, Django REST Framework, PostgreSQL, React + TypeScript, Tailwind CSS, JWT, Redis, Celery, Docker, and an LLM API.

The platform should have three roles: Candidate, Recruiter, and Admin.

Core features:

Secure JWT authentication and role-based access control

Candidate profiles and resume upload (PDF/DOCX)

Resume parsing and AI-powered resume scoring/feedback

AI job-description analysis

Resume-to-job matching with a 0–100 score, matched skills, missing skills, and improvement suggestions

Job creation, search, filtering, bookmarking, and applications

Candidate application tracking

Recruiter dashboard with applicants, match scores, shortlisting, and analytics

Candidate dashboard with recommended jobs and resume insights

Real-time notifications and email notifications using Redis/Celery

REST APIs with Swagger/OpenAPI documentation

PostgreSQL database with proper relationships, indexes, and constraints

Responsive modern React UI

Unit/API tests with Pytest

Docker + Docker Compose

GitHub Actions CI/CD

Production-ready security, error handling, logging, and environment-variable configuration

Use clean architecture, reusable components, type hints, proper validation, and industry-standard coding practices.

Do not build everything at once. Start by providing the system architecture, database schema, folder structure, API design, and development roadmap, then implement the project phase by phase.

The final application should look like a real SaaS product, not a basic CRUD/college project.
